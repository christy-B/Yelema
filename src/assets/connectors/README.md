# Logos des connecteurs

Déposez ici le logo de chaque connecteur, en **SVG** de préférence (ou PNG/WebP),
**nommé d'après le `provider`** du connecteur. Le logo s'affiche automatiquement
sur l'écran « Connecteurs » dès qu'il est présent ; sinon, une pastille colorée
avec l'initiale sert de repli.

Fichiers attendus (un par connecteur) :

notion · gdrive · sharepoint · confluence · slack · teams · gmail · outlook ·
salesforce · hubspot · pipedrive · quickbooks · sage · stripe · postgres ·
mysql · bigquery · snowflake · s3 · dropbox · onedrive · whatsapp · facebook ·
instagram · tiktok

Exemple : `notion.svg`, `whatsapp.svg`, `facebook.svg`…

Idéalement des logos carrés ou centrés sur fond transparent (ils sont affichés
dans une tuile blanche).
